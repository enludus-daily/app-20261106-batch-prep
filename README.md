# 段取りラン（作り置きタイムアタック）

週末の**作り置き**を、何品かまとめて作る順番（ルート）にして、そのルートを**走る**（タイムアタック）iOS アプリ（SwiftUI・iPhone / iPhone Duo）。
工程が終わるたびに「できた」でスプリットを刻み、目安・自己ベスト（ゴースト）と勝負する。ゴールするとタイム・ランク・1 品ずつより何倍速か・並行の割合。作った品を期限までに食べきると、そのランが「完食」になる。
enludus-daily の 2026-11-06 のアプリを、2026-11-09 に監督の依頼で作り直したもの（記録：enludus-daily/daily-ideas#6、基準は #9）。旧名「段取り帖」。

## だれの・どんな困りごと
- 作り置きで何品も作ると、**順番（段取り）が分からず時間がかかる**。雑誌が「2 時間で 16 品」のタイムスケジュールを手で組んで載せているほど（FRaU https://gendai.media/articles/-/68768 ）。
- 段取りを出すアプリ（Racook、ParaChef）はあるが、**段取りどおりに手を動かすのはしんどいまま**。作ったあと**食べ忘れて捨てる**。
- 組み合わせ（idea-fusion）：**作り置き × タイムアタック（RTA）**。「作り置きなのに RTA みたい」。手を動かすこと（工程を済ませる）と食べきること（完食）が、そのまま遊びの入力になる。

## できること
1. **今週のお題**：週ごとに変わるコース（無料の組み合わせ）。今週のベスト・自己ベスト・1 品ずつだと何分。
2. **コース**：品を選ぶ（組み合わせ 8 つ、レシピ 50 品）→ 手（1 本）・コンロ（1〜3 口）・レンジ・グリルの空きから段取りを計算（`App/Sources/Scheduler.swift`、残りの工程が長い品から始める貪欲法）。タイムラインは行ごとに手・コンロ・待つを分け、帯には品の番号だけ。説明は下の「ルート」の一覧（押す目安の時刻つき）。買い物リストは売り場ごと。
3. **ラン**：大きな経過時間、目安との差、自己ベストとの差（ゴースト）、目安内で続けて押すと「目安内 ×3」のコンボ（遅れると途切れる）、今の工程、動いている待つ工程の残り時間、大きな「できた／仕掛けた」。押しまちがいは 1 つ戻せる。アプリを閉じても続きから。
4. **結果**：タイム・ランク（S〜D、目安との比）・自己ベストの更新・1 品ずつより何倍速か・2 つ以上が同時に進んでいた割合・スプリットの差。共有カード（数字と器の絵だけ）。
5. **冷蔵庫**：ランで作った品が期限の近い順に並ぶ。1 食たべた・食べきった・冷凍・捨てた。全部食べきるとそのランが「完食」、完食が続いた数。
6. **お知らせ（任意）**：ラン中に仕掛けた待つ工程が終わる時刻と、夕方 18 時に今日食べきりたい品がある日だけ、ローカル通知（端末の中だけ）。許可しなくても全部使える。
7. **レシピ**：手で書いた作り置き 50 品（無料 24 品）。分類ごとに違う器の絵、中身の色と飾りで品を見分ける。

ランの計算（`App/Sources/Run.swift`）：ルートは「手の工程は終わったとき、待つ工程は仕掛けたとき」の順。ゴールは最後に押した時刻と待つ工程が終わる時刻の遅いほう（早く仕上がったら押した時刻）。

## 画面の参考（ui-reference）
- **StudyReel**（トーン）：sky `#9EC3E2` の 1 系統、差し色 peach `#F4BBA4` は自己ベスト・今の工程だけ、セリフの大きな数字（字間を詰める）、細い線、弱い影。
- **Strava / Nike Run Club**（流行りのランのアプリ）から借りたもの：
  1. ラン中の「巨大な経過時間＋大きな 1 つのボタン」→ ラン中の画面
  2. 終了画面の「大きなタイム＋自己ベストの印＋スプリットの差の一覧」→ 結果の画面
  3. 数字だけの共有ステッカー → 共有カード
- iOS 26 の標準の `TabView`（下に浮くガラスのタブバー、スクロールで小さくなる）。前の版の「右に浮いたタブの列（サイドバー）」はやめた。
- **Duo**：内側（regular）では、ラン中に左にタイムライン（今の線）とルート、右に今の工程。コースの画面も左右に分ける。並べ方は size class で決める。

## 世界観・トークン
- このアプリでは〔器（深皿・小鉢・保存瓶・汁椀・弁当箱・保存袋）〕が〔品の印〕に、〔まな板・コンロの口・レンジ・グリル〕が〔タイムラインの行〕になる。どれも自作の Canvas（`Parts.swift` の `DishIcon`・`LaneGlyph`）。和・紙・方眼・テープは使わない。
- 色（`Theme.swift`）：sky 1 系統（accent `#9EC3E2` L0.75・soft `#E1EDF6`・deep `#5E8DB8` は白文字のボタンと小さな文字だけ）、地 `#F3F6F9`、文字 `#2E3A46`。料理の中身の淡い色（milktea・matcha・butter、L0.74〜0.75）は小さな器の絵の中だけ。`scripts/tone-check.py` は exit 0。
- 書体：大きな数字と見出しはセリフ（字間を詰める、`monospacedDigit`）、本文はサンセリフ、小さなラベルは字間 0.6。
- ライトに固定（淡い水色と白の世界観を保つため。StudyReel と同じ判断）。最低 iOS 26（Liquid Glass の標準の部品を使うため）。

## 手応えの表
| できごと | 動き | 振動 | 音 |
|---|---|---|---|
| 押す・選ぶ | ボタンが 0.97 倍に縮む。品の札が加わる | `.selection` | なし（台所で使うので鳴らさない） |
| 1 つ成功（できた・仕掛けた） | 今の工程の札が左へ抜け、次が右から入る（spring 0.42/0.86）。上の進み具合が伸びる | `.impact(medium, 0.8)` | なし |
| 連続（目安内で続けて押す） | 「目安内 ×N」の札が 1.4 倍から縮んで入る | `.impact(heavy)`、続くほど強く | なし |
| 待つ工程が終わる | 「動いているもの」の帯が満ちて消える（画面を消していれば通知） | `.success` | 通知の音だけ |
| 失敗（目安を過ぎて押す・戻す） | コンボの札が消える／1 つ前に戻す／Pro の品・品数の上限は一文か課金の画面 | `.warning`（コンボが切れたとき）・`.selection` | なし |
| 完了（ゴール） | 結果の画面。ランクの丸が 0.6 倍からふくらむ（spring 0.5/0.8） | `.success` | なし |
| 場面の切れ目 | ラン中は全画面、結果はシート、閉じると冷蔵庫へ | — | なし |
「視差効果を減らす」がオンなら、移動とスプリングを止めてフェードだけにする。

## 課金

### 形と値段
- **買い切りの Pro ¥800**（非消耗型・ファミリー共有あり、`com.enludus.daily.004.pro`）。レシピの中身は増え続けないので、サブスクにしない（続けて増える価値を 1 行で書けない）。
- 無料：今週のお題・段取りの計算・ラン・結果・ランク・自己ベスト・冷蔵庫と完食は全部無料。レシピ 24 品・組み合わせ 4 つ・1 回 3 品まで・記録は新しい 5 本まで。
- 払う前に試せる：**はじめてのランは 8 品まで**、**ゴーストは 1 回だけ無料**。
- 課金の画面は、**はじめてのランの結果を閉じた直後に 1 回だけ**（同じ日に自動で 2 回は出さない）と、Pro の物に触れたとき・設定から。購入を復元あり。値段は StoreKit の `displayPrice`。

## 手元（Mac）で開く
```sh
brew install xcodegen
xcodegen generate
open BatchPrep.xcodeproj
```
StoreKit の確認は `Configuration.storekit` をスキームに設定する。
